# VSCode/ium Config

A personal repository to track VS Code and VSCodium configurations across platforms.

## Usage

Sync your local editor configurations to the root of this repository by running:

```bash
python get_configs.py # optional [-d | --directory] for saving into a folder at the script root.
```

Then **commit** and never spend time tweaking again!

----

Includes:  `settings.json`, `keybindings.json`, `tasks.json`, snippets AND an `extensions.json` of current profile extensions installed.
